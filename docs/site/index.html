Alei

Official Language Standard: v1.1.0-RC (AD-2026-001)

An open, human-first constructed literary language engineered for clear expression, transparent semantics, and poetic elegance.

1. The Language at a Glance

Alei is created for human speakers, writers, and learners. It balances a productive root inventory with an analytical attribute layer, allowing speakers to describe novel or intricate concepts without opaque jargon.

Speaker A: Alei! Sai süli le?
[aˈlei̯ | sai̯ ˈsy.li le]
"Hello! Are you well?" / "Merhaba! İyi misin?"
Speaker B: Alei! Mei süli. Sai yelen ke miraven mein le?
[aˈlei̯ | mei̯ ˈsy.li || sai̯ ˈje.len ke miˈra.ven mei̯n le]
"Hello! I am well. Can you help me?" / "Merhaba! Ben iyiyim. Bana yardım edebilir misin?"
Speaker A: Ei, Mei yelen ke miraven sain. Süli vel!
[ei̯ | mei̯ ˈje.len ke miˈra.ven sai̯n || ˈsy.li vel]
"Yes, I can help you. Have a safe journey!" / "Evet, sana yardım edebilirim. Yolun açık olsun!"

2. What Makes Alei Unique?

Human First

Children, novelists, and everyday conversationalists can use Alei naturally. It is not an artificial AI-only protocol.

Transparent Semantics

Describe objects analytically: meyar-ro-yenar-li-reş-ze-selim (tree-fruit, typically red and sweet) communicates clear perceptual features.

Governed Evolution

Language rules evolve through transparent RFCs and owner decisions. No invented roots pass silently into the canon.

Epistemic Honesty

Alei tools reject hallucinated deductions. Unknown names like Jajaya require explicit definitions.

4. Get Started in 60 Seconds

Clone the open source repository and test the command-line interface:

# Clone and install in editable mode
git clone https://github.com/egecagintepe/alei-language.git
cd alei-language
python -m pip install -e .

# Look up the approved help root Mirav in v1.1.0
python -m alei_language.cli lookup mirav --version 1.1.0

# Parse a full sentence with valency checking
python -m alei_language.cli parse-ast "Mei da sileven tüvanan." --version 1.1.0
