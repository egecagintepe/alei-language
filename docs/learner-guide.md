# Learner Guide

Start with `Alei!` then `Sai süli le?` and `Ei, mei süli.` See the everyday dialogue. Try `Mei saelen sain.` and `Mei sain saelen.`; the second emphasizes the object. Ask a human or file an issue when a form is unclear.
