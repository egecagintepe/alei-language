# Start here

Alei! This is a working constructed language, still being tested. Begin with the [Turkish guide](../README.tr.md), the [original standard](../standard/README.md), then try the [dialogue](../examples/everyday-dialogue.md). To suggest a word or raise a grammar question, use the repository issue forms when available; no coding is necessary.

Alei is the official human language name; [v1.1.0 release notes](release-v1.1.0.md) explain preferred Mirav/Miraven and v1.0 compatibility. AleiFlow is a separate experimental programming-language track.
