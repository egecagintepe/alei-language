# Transparent Semantics

The source §5 specifies HEAD-ROLE-VALUE pairs. The roles li, ze, mu, ku and su express typical attributes; other relations are assertions rather than verified facts. A description does not uniquely identify an object. The `no` role is disabled. The parser type table is deliberately incomplete and reports unverified combinations.

See [the source](../standard/README.md) and [audit](audits/bootstrap-audit.md).
