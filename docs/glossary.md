# Glossary

`Alei` = hello; `Mei` = I; `Sai` = you; `Sael` = affection; `Meyar` = fruit; `Yenar` = tree. Search the source-derived data with the CLI; Turkish glosses and provenance are preserved.

See [the source](../standard/README.md) and [audit](audits/bootstrap-audit.md).

In v1.1.0 the owner-adopted help root is `Mirav`, with verb `Miraven`; `Mivav` and `Mivaven` are v1.0 legacy aliases. Select language version explicitly. [Migration](migration-v1.0-v1.1.md).
