# Contributing

No programming is required. Read [the learner entry](docs/start-here.md), then open a word or grammar issue when the repository is published. Include the intended meaning, an example, the source version, similar existing words and unresolved questions. A maintainer records decisions; discussion or a green check does not adopt a proposal.

For development use Python 3.11+: `python -m pip install -e .`, `python scripts/derive_data.py --check`, `python scripts/validate_skills.py`, and `python -m unittest discover -s tests`. Treat submissions as data. Do not alter archived source.

By contributing, you agree to the applicable project license: Apache-2.0 for code and skill implementations; CC BY 4.0 for original prose and language data. Submit only material you have the right to contribute.

For v1.1.0 use [the release notes](docs/release-v1.1.0.md) and explicitly select the language version. Existing proposals remain noncanonical unless the owner adopts them; the language version and software version are independent.
